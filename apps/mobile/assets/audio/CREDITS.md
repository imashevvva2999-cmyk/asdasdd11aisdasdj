# Demo audio credits

These recordings are used as **demo audio** for all 13 catalog tracks so the Mmusic player can be tested with real playback. They are not the catalog recordings and are labelled "Demo audio" in the app (Now Playing → "Demo audio" → credits sheet).

Files are unmodified originals downloaded from the author's site: the first two on 2026-10-08, the remaining eleven on 2026-10-10. All were downloaded via the exact URLs incompetech.com's own catalog JSON (`pieces.json`) and official agent-access page (`incompetech.com/agent-section/`) publish for each title, and every file's byte size was checked against that catalog's declared `Content-Length` before being accepted — this is the verification that applies to all 13 files without exception.

ID3 tags were additionally spot-checked where present, but coverage is uneven: `eternity.mp3`, `spellbound.mp3`, `late-night-radio.mp3`, and `airship-serenity.mp3` carry an embedded ISRC that matches the table below; `windswept.mp3`, `reminiscing.mp3`, `comfortable-mystery.mp3`, `one-sly-move.mp3`, `deliberate-thought.mp3`, and `winter-reflections.mp3` carry a "Kevin MacLeod" artist tag but no embedded ISRC (the ISRC in the table for these comes from `pieces.json` only); `equatorial-complex.mp3` carries no title, artist, or ISRC tag at all (only `Logic Pro X` encoder metadata) — its identity rests solely on the exact `Content-Length` match against the catalog entry for "Equatorial Complex".
