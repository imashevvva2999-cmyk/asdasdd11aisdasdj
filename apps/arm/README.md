# apps/arm — заглушка

АРМ (автоматизированное рабочее место) — внутреннее рабочее место оператора/модератора Mmusic [Доп]. Окончательное назначение требует подтверждения. Сейчас здесь нет кода.

## Этап M1 (2026-10-21)

Фундамент АРМ готов: Vite + React, оболочка с навигацией, RU/EN, предварительные роли (переключатель только для разработки), вымышленные демо-данные с «Сбросить демо-данные». **Локальный прототип без авторизации — не размещать в сети.** Порты: dev 5182, preview 5183. План, решения и открытые вопросы — `docs/arm-crm-plan.md`.
