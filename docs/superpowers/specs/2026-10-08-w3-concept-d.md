## 1. Идея: «сцена»

Наверху сайта — **сцена**: полоса цвета обложки играющего трека, на которой стоит сам трек. Обложку можно листать, рядом крупное название и управление.

Now Playing — **та же сцена, выросшая на весь экран**:
- обложка увеличивается и переезжает в центр;
- навигационная пилюля превращается в строку «Playing from…»;
- капсула плеера раскрывается в полную панель управления;
- разделы ниже растворяются.

Это одно движение, а не переход между экранами (`d-transition.png` — кадр из середины).

**Что взято:**
- **из B:** адаптивный цвет обложки, Home начинается с музыки, карусель обложек, Lyrics и Queue рядом с обложкой;
- **из C:** плавающая навигация-пилюля, плавающая капсула плеера, воздух, отсутствие плашек и серых карточек.

**Что нового и что делает D узнаваемым:**
- сцена — «горизонт» цвета, а не заливка всей страницы;
- сцена и плеер — один объект;
- капсула появляется только тогда, когда сцена ушла из вида, поэтому управление никогда не дублируется на экране.

**Цвет.**
- В макетах играет **Horizon** с сине-сумеречной палитрой: фиолетового заметно меньше, коралловый Play хорошо читается.
- Палитры по-прежнему берутся из обложки: у тёплой обложки сцена тёплая, у синей — синяя.
- Цвет занимает только сцену; ниже — спокойный тёмный фон `#0A0A0C`.
- Без стекла, без размытия, без свечения: плавающие элементы — сплошная поверхность `#141418` с тонкой границей.

## 3. Доступность функций

| Функция | Где в D |
|---|---|
| Search, Library, Home | Пилюля навигации; поиск — иконка и клавиша `/` |
| Уведомления, профиль (Settings, Account, Support History, Artist Studio) | Пилюля, иконки справа |
| Воспроизведение | Сцена (вверху Home), капсула (при прокрутке и на других страницах), полная капсула в плеере, медиа-клавиши и экран блокировки (W2) |
| Lyrics, Queue | Кнопки на сцене и в капсуле, переключатель в плеере, клавиши L / Q |
| Like, Add to playlist, Support, Audio | Сцена (Liked), капсула плеера, кнопки в плеере на планшете |
| Смена трека | Свайп или перетаскивание обложки, кнопки ⏮ ⏭, клавиши |
| Страницы артиста, альбома, плейлиста, Options | Без изменений: ссылки, правый клик (действия листа Options) |
| Телефон | Без изменений: мобильный Dynamic Premium Player |

## 4. Движение — только по делу

- **Развернуть / свернуть плеер:** одна плавная анимация около 350 мс (сцена, обложка, капсула, пилюля движутся вместе). При уменьшении движения — проявление.
- **Смена трека:** обложка уезжает за пальцем или курсором, цвет сцены плавно меняется вслед за ней (около 600 мс после отпускания).
- **Появление капсулы при прокрутке:** короткое всплытие снизу.
- **Наведение:** обложка приподнимается на 4 px, появляется Play.
- **Ничего не движется само по себе:** нет «дышащих» фонов и постоянных анимаций. Мини-эквалайзер у играющей строки неподвижен при уменьшении движения.

## 5. Сравнение B, C и D

| Критерий | B. Living Canvas | C. Floating Minimalism | **D. Floating Canvas** |
|---|---|---|---|
| Узнаваемость, непохожесть на Spotify / Apple Music | Высокая | Средне-высокая | **Высокая**: сцена-горизонт и единый объект «сцена → плеер» |
| Связь с Dynamic Premium (цвет, карусель, жест) | Максимальная | Средняя | **Максимальная** |
| Непрерывность Home → Now Playing | Портал → плеер | Капсула → лист → плеер | **Сцена растёт в плеер; капсула и пилюля перетекают** |
| Количество цвета | Вся страница | Почти нет | **Только сцена; ниже спокойный тёмный фон** |
| Визуальный шум | Средний | Самый низкий | **Низкий** |
| Навигация | Вертикальный «позвоночник» | Плавающая пилюля | **Плавающая пилюля** |
| Управление при прокрутке | «Пульс» в навигации | Капсула | **Капсула** (только когда сцена не видна — без дублирования) |
| Lyrics и Queue | Колонка рядом с обложкой | Плавающий лист | **Колонка рядом с обложкой + строка в фокусе в обычном режиме** |
| Узкие окна и планшет | Средне | Легко | **Легко**: сцена складывается, пилюля и капсула компактны |
| Сложность реализации | Средняя | Ниже | **Средняя**: многое переиспользуется из мобильного плеера (`carouselPos`, `expandProgress`, палитры) |
