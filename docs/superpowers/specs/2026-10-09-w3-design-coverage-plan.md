## 1. Язык Floating Canvas — единые правила для всего сайта

| Правило | Как применяется |
|---|---|
| **Сцена из обложки** | У страниц сущности (артист, альбом, плейлист, жанр, Liked Songs) верх окрашен цветом её обложки или фото и уходит в фон `#0A0A0C` — как сцена на Home. Фото артиста и жанра растворяется в сцене без шва. Цвет только сверху; разделы ниже — на спокойном фоне |
| **Без цвета там, где нет обложки** | Search, Library, Profile, Settings, история доната — нейтральный фон; цвет дают только сами обложки |
| **Типографика** | Plus Jakarta Sans 800 для заголовков (крупные, по левому краю — «журнальный» тон), Inter для текста. Заголовки разделов — 22 pt на телефоне, 26 px на десктопе |
| **Главное действие** | Один коралловый элемент на экране: Play, «Play All», «Listen Now», «Support with … сом», «Create Playlist», «Done». Остальные действия — тихие пилюли на полупрозрачном тёмном фоне |
| **Списки без карточек** | Строки треков, артистов и настроек — прямо на фоне, без серых подложек; разделение — воздухом или тонкой линией. Подложка только у плавающих элементов и полей ввода |
| **Сетки обложек** | Обложка — сама себе карточка: картинка со скруглением, подпись снизу. На десктопе при наведении — коралловый ▶ |
| **Плавающие элементы** | Пилюля навигации и капсула на экранах вкладок; на страницах контента — только капсула. Сплошная поверхность `#141418`, тонкая граница, без стекла и размытия |
| **Листы** | Сплошной лист `#141418` над затемнённой страницей, ручка сверху, скругление 28 pt; без размытия |
| **Пустые состояния** | Иконка в тихом круге, заголовок, подсказка, одно действие. Без свечения (сейчас у `EmptyState` вариант `hero` светится — убрать) |
| **Формы** | Поля — заполненные `#141418` со скруглением 16 pt, переключатели коралловые, одна коралловая кнопка внизу |
| **Движение** | Только в ответ на действие: открытие листа, раскрытие плеера, смена трека. Ничего не «дышит» само |

## 4. S-11 — второй вариант плейлиста (OQ-18), без выдумывания требований

**Открытый вопрос OQ-18** (`docs/open-questions.md`): две разные страницы плейлиста — какая каноничная. Предложение из документа (S-11 — для редакционных, S-10 — для пользовательских плейлистов) **не утверждено**.

**Что есть сейчас:** S-10 и S-11 — один маршрут `/playlist/[id]` и одна общая раскладка. Редакционный плейлист показывает метку «Editorial Playlist» и автора, пользовательский — «Your playlist».

**Чего нет из макета S-11:** «Find in playlist» (поиск внутри плейлиста), фильтры, блок «About This Playlist».

**Что делаем:**
- макет Floating Canvas для S-11 не создаю, чтобы не придумывать поведение поиска, фильтров и содержание «About»;
- до решения OQ-18 оба варианта используют общий макет `playlist`;
- после решения — небольшой отдельный макет S-11 на тех же компонентах.

## 5. Планшет и десктоп для этих семейств

- **Страницы сущностей** (артист, альбом, плейлист, жанр):
  - сцена во всю ширину;
  - на десктопе крупный заголовок 72–96 px слева, обложка или фото справа;
  - треки — таблицей (№, название, длительность, ⋯; у артиста ещё альбом), ▶ при наведении на строку.
- **Search:** на десктопе тренды и Browse all — в две колонки; поле с подсказкой клавиши `/`.
- **Library:** список на телефоне, сетка в 4 колонки на планшете, в 6 — на десктопе.
- **Профиль, настройки, история:** колонка до 720 px по центру.
- **Листы:** на ≥ 600 px — диалог по центру шириной 440 px, на телефоне — нижний лист. Меню ⋯ в капсуле — как утверждено в спецификации этапов.

## 6. Риски и компромиссы

| Риск | Мера |
|---|---|
| Нет палитр для артистов, плейлистов и жанров | Расширить существующий генератор палитр (Pillow, локально) с той же проверкой контраста ≥ 5 : 1; без палитры — нейтральная сцена |
| Нагрузка: сцена на каждой странице | Статический градиент, анимируется только в плеере; без размытия |
| Объём работы | Сначала общие компоненты (§2) — они переводят 16 экранов сразу; отдельные переработки — 7 экранов |
| Отличия от исходных макетов Stitch | Тексты, данные и действия сохраняются; меняется только визуальный язык (без свечения и серых карточек) |
| S-11 остаётся частичным | Явно задокументировано (§4); ждёт решения OQ-18 |
