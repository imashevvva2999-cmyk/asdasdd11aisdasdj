# Mmusic — Living Music Experience: три концепции десктопа

> Дата: 2026-10-08. Статус: **на выбор**. Код приложения не менялся. Реализация — только после выбора и утверждения.
> Заменяет визуальное направление `2026-10-08-w3-responsive-design.md` (вы оценили его как слишком похожее на Spotify). Технические части той спецификации — точки перелома, клавиатура, доступность, маршруты — остаются в силе для выбранной концепции.

**Материалы** (`docs/superpowers/specs/w3-concepts/`):
- `compare.png` — все три концепции рядом: строки A, B, C; столбцы Home, Now Playing, Queue / Lyrics;
- отдельные скриншоты 1440 × 900: `a-*.png`, `b-*.png`, `c-*.png`;
- живые HTML-макеты: `a-editorial.html`, `b-canvas.html`, `c-floating.html` (открыть в браузере, параметр `?v=home|player|queue`).

**Общее для всех трёх:**
- только существующие экраны, разделы, данные и действия (For you, Late Night Flow, Trending now, New releases; Lyrics, Queue, Like, Add to playlist, Support, Audio, Search, Notifications, Profile);
- логотип-эквалайзер, Plus Jakarta Sans и Inter, коралл только для главного действия и прогресса, золото для редакционных меток, палитры обложек;
- без стекла и размытия, без постоянной анимации;
- телефон и Dynamic Premium Player на телефоне не меняются.

## A. Immersive Editorial — «журнальный разворот»

**Идентичность.** Музыка подаётся как журнал: огромные заголовки Plus Jakarta Sans 800 с плотным кернингом, асимметричная сетка, обложки разного масштаба. Главный выразительный инструмент — **типографика**; цвет почти не используется.

| | |
|---|---|
| **Навигация** | Текстовая «шапка» сверху: логотип, Home / Search / Library (активный пункт подчёркнут кораллом), поиск-строка с подсказкой `/`, уведомления, профиль. Боковой панели нет |
| **Плеер** | «Колонтитул» внизу высотой 56 px — строка текста «Now playing · Midnight Mirage · Solaris Echo», время, кнопки, Lyrics / Queue. Прогресс — коралловая линия во всю ширину над колонтитулом, её можно тянуть |
| **Home** (`a-home.png`, `a-home-lower.png`) | Главный материал — обложка Late Night Flow выходит за левый край, справа заголовок 104 px. «For you» — указатель из шести пунктов, без плашек. Trending now — мозаика с одной крупной обложкой, New releases — ряд |
| **Now Playing** (`a-player.png`) | Разворот: слева обложка на всю высоту (перетаскивание и ← → листают треки), справа на фоне палитры заголовок 84 px, действия (Liked, Add to playlist, Support artist, Audio) и текст песни как вёрстка |
| **Queue / Lyrics** (`a-queue.png`) | Вкладка «Up next» — пронумерованное «содержание» (номер — это реальный порядок воспроизведения), крупные названия, при наведении номер подсвечивается и появляется ▶ |
| **Переходы** | Клик по колонтитулу — обложка «раскрывается» в левую страницу разворота, текст справа проявляется. Смена вкладки Lyrics ↔ Up next — подчёркивание переезжает |

- **Плюсы:** самый узнаваемый и «премиальный» характер; отлично подаёт редакционный контент и локальную сцену.
- **Минусы:**
  - плеер в виде строки текста менее заметен для новичков;
  - крупная типографика требует аккуратной адаптации к узким окнам и длинным названиям.

## B. Living Canvas — «страница и есть плеер»

**Идентичность.** Вся страница окрашена палитрой играющего трека: при смене трека «живёт» весь холст, а не только плеер. Это прямое развитие Dynamic Premium — тот же адаптивный цвет, тот же переход «свернуто ↔ развернуто». Главный выразительный инструмент — **цвет музыки**.

| | |
|---|---|
| **Навигация** | Тонкий «позвоночник» слева (92 px): логотип, Home / Search / Library с подписями, профиль. Поиск — пилюля сверху |
| **Плеер** | Отдельной панели нет. Наверху Home — **портал** играющего трека: крупная обложка, название 76 px, полный набор кнопок, шкала, Liked / Lyrics / Up next / Open player. Когда портал уходит при прокрутке, в «позвоночнике» появляется **пульс** — круглая обложка с кольцом прогресса и паузой (`b-home-scrolled.png`) |
| **Home** (`b-home.png`, `b-home-scrolled.png`) | Портал, затем «For you» крупными обложками без подложек. Ниже Late Night Flow и Trending now; фон постепенно уходит в тёмный |
| **Now Playing** (`b-player.png`) | Холст в полном цвете. Карусель обложки видна целиком: соседние треки выглядывают по краям. Справа текст песни, внизу Liked / Add to playlist / Support / Audio |
| **Queue / Lyrics** (`b-queue.png`) | Вкладка «Up next» — «река» следующих треков с обложками; ближайший помечен «Next», при наведении появляется ▶ |
| **Переходы** | Обложка портала (или пульса) плавно вырастает в обложку Now Playing — без смены экрана, холст уже нужного цвета. Свайп / перетаскивание обложки меняет цвет всей страницы вслед за жестом, как сейчас на телефоне |

- **Плюсы:**
  - максимально «живой» и музыкальный;
  - продолжает уже сделанный Dynamic Premium (общая логика `carouselPos` / `expandProgress`);
  - самый короткий путь от просмотра к прослушиванию.
- **Минусы:**
  - цвет всей страницы меняется с каждым треком — нужен строгий контроль контраста (палитры уже проверены) и сдержанность в переходах;
  - без активного трека Home нужно спокойное «пустое» состояние портала.

## C. Floating Minimalism — «предметы в пустоте»

**Идентичность.** Тёмное пространство и несколько плавающих предметов на центральной оси: навигация-пилюля, капсула плеера, круглые обложки. Главный выразительный инструмент — **пустота и форма**. Плавающие элементы — сплошные поверхности `#141418` с тонкой границей и тенью, без стекла.

| | |
|---|---|
| **Навигация** | Пилюля сверху по центру: логотип, Home / Search / Library (активный — белая пилюля), поиск, уведомления, профиль. В плеере пилюля сжимается до «⌄ Playing from Horizon (Deluxe) ⋯» |
| **Плеер** | Капсула внизу по центру: обложка-круг, название, ⏮ ⏯ ⏭, Lyrics, Queue, «развернуть». Прогресс — тонкая линия цвета палитры по нижнему краю. В развёрнутом виде капсула шире: ♡, ⇄, шкала, ↻, Support, Audio, громкость |
| **Home** (`c-home.png`) | «For you» — полка круглых обложек (при наведении — белое кольцо и Play), ниже Late Night Flow. Много воздуха, никаких плашек |
| **Now Playing** (`c-player.png`) | Одна обложка по центру на круге цвета палитры, крупное название, под ним «строка в фокусе» — предыдущая, текущая и следующая строки текста. Стрелки ‹ › листают треки |
| **Queue / Lyrics** (`c-queue.png`) | Капсула «вырастает» вверх в плавающий лист с переключателем Lyrics / Queue; фон приглушается |
| **Переходы** | Капсула ↔ лист ↔ развёрнутый плеер — один и тот же предмет, меняющий размер. Навигационная пилюля перетекает в заголовок плеера |

- **Плюсы:** самый спокойный и лёгкий; минимум элементов; понятен с первого взгляда; хорошо масштабируется на любые окна.
- **Минусы:**
  - меньше «вау»-эффекта;
  - плавающая капсула может перекрывать контент внизу (нужен отступ);
  - полный текст песни прячется в лист;
  - мягкий край круга за обложкой близок к «свечению» — при выборе C его можно сделать чётким.

## Сравнение

| Критерий | A. Editorial | B. Living Canvas | C. Floating |
|---|---|---|---|
| Непохожесть на Spotify | Высокая | Высокая | Средне-высокая |
| Связь с Dynamic Premium | Средняя (палитра в плеере) | **Максимальная** (вся страница — палитра, тот же жест) | Средняя (круг палитры, линия прогресса) |
| Переход просмотр → прослушивание | Колонтитул → разворот | **Портал / пульс → плеер без смены экрана** | Капсула → лист → плеер |
| Простота для нового пользователя | Средняя | Высокая | **Высокая** |
| Текст песни | **Крупная вёрстка** | Крупно, рядом с обложкой | Строка в фокусе + лист |
| Узкие окна (1024–1279 px) | Сложнее (крупные заголовки) | Средне | **Легко** |
| Риск визуального шума | Низкий | Средний (цвет меняется) | **Самый низкий** |
| Сложность реализации | Средняя | Средняя (много переиспользуется из плеера) | **Ниже всех** |

## Рекомендация

**B. Living Canvas** — как основа. Он лучше всего отвечает идее «Living Music Experience»: музыка буквально окрашивает сайт, а переход от просмотра к плееру — один непрерывный жест, уже проверенный на телефоне.

Можно взять из A редакционную типографику для главного материала (крупный заголовок Late Night Flow), но только если вы этого захотите — в чистом виде выбор за вами.
