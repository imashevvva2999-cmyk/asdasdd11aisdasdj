## 1. Обзор проекта

| Параметр | Значение |
|---|---|
| Название | **Mmusic** [Д] |
| Тип продукта | Мобильное приложение для стриминга музыки [Д] |
| Бизнес-контекст | Часть цифровой экосистемы банка. В дизайне указан **MBANK**: «MBANK account», «MBANK Connected ID», «Powered by MBANK Core Architecture», «℗ Mmusic Recordings / MBANK Sound» [Д], подтверждение — OQ-01 |
| Валюта | Сом (KGS) — суммы донатов в «сом» [Д]; на одном оверлее есть `$` (OQ-08) |
| Целевая платформа | **Подтверждено 2026-10-06:** мобильное приложение **и** WebView-интеграция внутри MBANK (OQ-02 отвечен; технические детали WebView — OQ-53). Макет — мобильная ширина 390pt [Д]; в DESIGN.md также описаны планшет и десктоп, но точные ОС/формфакторы не подтверждены (OQ-03) |
| Визуальный стиль | Dark-first, «Nocturne Audio»: тёмный фон, акцент коралловый `#FF4B4B`, glassmorphism [Д] |

### 1.1 Назначение

Mmusic даёт клиентам банка современный музыкальный сервис внутри экосистемы банка: прослушивание, поиск, личную библиотеку и плейлисты. Отличительная функция по дизайну — **прямая поддержка артистов деньгами** (донаты со счёта MBANK с биометрическим подтверждением) [Д].

### 1.2 Основная идея

«Премиальное ночное акустическое пространство» (DESIGN.md) [Д], где пользователь слушает музыку, открывает для себя локальную (кыргызскую и центральноазиатскую) и мировую музыку [Д: разделы «Kyrgyz Music», «Trending in Bishkek», «Central Asian Wave»] и в один тап поддерживает любимых артистов через банк [Д].

### 1.3 Целевая аудитория [Доп]

Дизайн не описывает аудиторию явно. Допущения, требующие подтверждения (OQ-06):

- действующие клиенты MBANK со смартфоном;
- слушатели локальной кыргызской и центральноазиатской музыки;
- любители качественного звука (Lossless, Dolby Atmos в дизайне) [Д];
- фанаты, готовые финансово поддерживать артистов [Д].

### 1.4 Проблемы пользователя, которые решает приложение [П]

| Проблема | Решение в дизайне |
|---|---|
| Сложно найти локальную музыку в глобальных сервисах | Отдельные разделы Kyrgyz / Central Asia [Д] |
| Нет простого способа поддержать артиста деньгами | Донат в 2 тапа со счёта банка [Д] |
| Неудобная оплата зарубежных сервисов | Оплата внутри банка; направление Free + Premium подтверждено 2026-10-06, но подписка в дизайне не задизайнена и точная модель не определена (OQ-05) |
| Разрозненная музыка | Единая библиотека: лайки, плейлисты, артисты, альбомы, загрузки [Д] |

## 2. Цели проекта

### 2.1 Продуктовые цели [П]
- Выпустить первую версию с **полным** подтверждённым core-функционалом (решение лида продукта 2026-10-06, не сокращать без отдельного согласования): Home, Search, Library, Player / Now Playing, Lyrics, Playlists, Downloads, Donations / Artist Support — и утверждённый Artist Flow (Profile Hub → Become an Artist → Artist Setup → Artist Dashboard → Upload Track, S-25…S-28, раздел 3.18). Подкасты, Lossless/Atmos, AI-функции и коллаборативные плейлисты в этот подтверждённый список не входят — их скоуп остаётся открытым (OQ-20, OQ-22, OQ-24, OQ-25).
- Точно воспроизвести дизайн-систему Nocturne Audio.
- Стабильное фоновое воспроизведение и управление с экрана блокировки [Т].

### 2.2 Цели пользователя [П]
- Быстро найти и включить музыку (≤ 3 тапов от главной до воспроизведения).
- Сохранять треки и собирать плейлисты.
- Поддерживать артистов и видеть историю поддержки [Д].

### 2.3 Бизнес-цели [П] — требуют подтверждения банком (OQ-43)
- Рост вовлечённости клиентов в экосистему банка (DAU/MAU, время в приложении).
- Рост транзакционной активности (донаты через счёт MBANK).
- Привлечение молодой аудитории.
- Позиционирование банка как поддерживающего локальную музыкальную сцену.

### 2.4 Возможная ценность для экосистемы банка [П]
- Новый регулярный сценарий использования продуктов банка (ежедневное прослушивание).
- Транзакции P2Creator (донаты) и, возможно, подписка (OQ-05).
- Данные для лояльности: бейдж «MBANK VIP SOUND» в профиле [Д] — смысл статуса не определён (OQ-05, OQ-12).
