# Mmusic — трекер задач (CEO Demo и далее)

> **Формат работы (с 2026-10-10):** работаем **строго по одной явно одобренной задаче за раз**. Ни одна задача не начинается и не считается завершённой без отдельного явного решения пользователя. См. правила ниже.

## Правила

1. В работе — только ОДНА явно одобренная задача одновременно.
2. Никогда не переходить к следующей задаче автоматически.
3. Никогда не помечать задачу APPROVED без явного подтверждения пользователя.
4. Сохранять весь ранее одобренный UI и функциональность.
5. Не удалять, не заменять и не забывать задачи молча.
6. Трекер обновляется после каждой завершённой задачи.
7. По каждой задаче — отчёт: что изменено, что протестировано, что осталось незавершённым.
8. Без одобрения — не коммитить, не пушить, не деплоить.
